Detailed Description

TransportPosition.

A tagged union representing a transport position in either:

  • absolute samples (TSamples), or
  • musical quarter notes (TQuarterNotes, a.k.a. PPQ).

Hosts may choose which representation they honor. Plug-ins should use ::Type to indicate which field is valid.

Note
TransportPosition is only meaningful for actions requiring a position (Locate, SetCycleStart, SetCycleEnd, etc).
